drone simulator.


# Usage

## 1. local usage

style 1:

```bash
$ python -m http.server 8000 --directory ./drone-sim
```

style 2:

```bash
$ cd drone-sim/
$ python -m http.server 8000
```

style 3:

```bash
$ cd drone-sim/
$ python -m http.server 8000 --bind 0.0.0.0
```


## 2. online usage
